## 1. 定位

第一人称、PvPvE、办公题材的 3D 搜打撤。一座**不设固定层数**的企业巨构（垂直城市）“方舟大厦”，每局现生成**固定 4 层**可玩垂直空间，带得走的才算数。
参考坐标系：塔科夫（风险与收益、装备丢失）、三角洲（枪感与信息）、办公室（题材与空间）。

## 3. 玩法决策

| 维度 | 决定 |
|---|---|
| 视角 | 第一人称，无自动瞄准 |
| 对抗 | PvPvE：先 AI 对手，玩法成立后接真人联机 |
| 结构 | ~~Run 制，单局逐层下坠~~（已取消，见 §12） |
| 起点 | 已解锁的最高存档层（初始 50） |
| 存档点 | ~~每 5 层记录进度~~（已取消，2026-11-27） |
| 安全层 | 只有 50/40/30/20/10（避难层，无战斗）；45/35/25/15/5 只记录进度，仍是危险区 |
| 解锁 | 活着抵达即永久解锁，不需要从该层撤离 |
| 撤离 | **两端出生、对端撤离**：每层 2 个点（一局 8 个），每端只有 4 个（近层 2 个拉闸、远层 2 个免费）、两端不通用；拉闸后才揭示近层点；读条 20–30s；撤离后物资入仓库（2026-11-27 第三轮，06 §4.2） |
| 下坠 | 保留全部物资，进入下一层 |
| 死亡 | 丢失本局携带物资与装备（存档点已取消，见 §12） |
| 单层玩家 | **最多 16 人：4–6 队（含 AI 队）× 每队 1–4 人；真人 ≥8 才开局**；F1/F4 各出生 2–3 队 |
| 单层 AI | 30–40 上限 |
| 单层时长 | 10–15 分钟 |
| 单层对局 | 每层是独立匹配的一局；下坠 = 离开当前局、进入下一层的新局 |
| Boss | 随机层刷新，无固定层、无冷却，可能连续多层都有 |
| 组队 | 存活队员同进同退；队友死亡后解除约束；可主动脱离队伍 |
| 关卡 | 全部程序生成，0 手工层 |
| 武器 | 办公用品（皮荒诞、骨严肃） |
| 硬核度 | 中等：部位伤害、护甲耐久、网格背包、负重、真实弹道；不做骨折/手术/藏身处 |
| 美术 | 先风格化写实低多边形，验证后转 PBR |
| 叙事 | 背景故事 + 收集品线索，不做线性战役 |

## 4. Run 规则

| 事件 | 结果 |
|---|---|
| 开局 | 从已解锁的最高存档层进入 |
| 逐层下坠 | ~~每层按种子生成；撤离点每层随机；物资全部保留~~（已取消，无下坠） |
| 成功撤离 | 物资入仓库，本局结束；下次仍从存档层开始，不保存当前深度 |
| 活着抵达存档层 | 永久解锁该层作为新起点 |
| 死亡 | 丢失本局携带战利品与身上装备，回最近已解锁存档层 |
| 组队 | 全队存活成员一起撤离或下坠；有人死亡后解除；可脱离队伍单独行动 |

示例：
- 50 开局 → 下到 47 撤离成功 → 下次仍 50 开局。
- 50 一路活着走到 45 → 45 永久解锁 → 下次可 45 开局。
- 死在 47 → 回 50（45 尚未解锁）。

## 5. 已确认假设

1. 到达即解锁：脚踩到 45 层就算，不需要从 45 层撤离一次。
2. ~~安全层只有 50/40/30/20/10~~（已取消，2026-11-27；存档点一并取消）：无 AI、无 PvP，只做整备、仓库、向下入口；45/35/25/15/5 只是存档点，仍然有 AI 和 PvP。
3. 撤离失败 = 死亡；撤离读条被打断只是取消重来，不算失败。

## 6. 全部程序化（2026-11-24 追加）

- 所有楼层由同一套生成器产出（总层数不设，按局生成）：普通层、收容/避难层、Boss 层、事件层。
- 手工层为 0。质量保障从摆场景转移到生成器约束、批量校验、Floor Lab 审图。
- 楼层类型 = 同一管线的不同约束配置：
  - 普通层：标准约束
  - 避难层：防火分区模板参数（无火源、双楼梯、独立通风）
  - Boss 层：随机 roll 命中时注入通高大厅 + Boss（无固定层、无冷却）
  - 事件层：事件注入参数（停电、漏水、火警、施工、封锁）

## 7. 尺度：企业巨构（2026-11-24 追加确认）

- 设定从“写字楼”升级为“企业巨构 / 垂直城市”：一家公司自建的方舟大厦，每层一个功能区；**不设总层数**，一局匹配现生成**固定 4 层**。
- 标准层 200×160（32,000㎡）；裙房 280×280（78,400㎡）；顶部 160×120（19,200㎡）。
- 全塔约 1.75 km²：海岸线 4 km² 的 44%，航天基地 0.36 km² 的 4.9 倍。
- 层高/净高：标准层高 4.2m / 净高 3.37m（吊顶板底）；实验室净高 5.4m（层高 6.0m，不吊顶）；裙房净高 6.0m；大堂 12m；中庭 8–12m。
- 200×160 为暂定值，用户试玩后可能调整；尺寸是生成器参数，改配置不重做美术。
- 每局 16 人 / 30,000–33,000㎡（约 2,000㎡/人），原生 AI 25–35，单局 30 分钟。

## 9. Boss 与逐层匹配（2026-11-24 追加确认）

- **Boss 随机刷新，无内置 CD**：**每局 20% roll 一次**，命中就刷在 **F2 或 F3**（避开有电梯卡的那层）；同局最多 1 个（2026-11-27 第三轮）。
- **一局 = 固定 4 层**（2026-11-27 第三轮）：不再是"每层一局"；层与层靠 2 条单层楼梯 + 中心电梯连通、同局共享计时与撤离。
- 因此"个人 24h 冷却"不再成立——每层都是新局，Boss 击杀记录只影响战利品/成就，不影响刷新。
- Boss 不再绑定固定楼层，也不因 Boss 存活关闭撤离点（保留为可选事件规则）。

对局分配（2026-11-24 确认）：

| 项 | 决定 |
|---|---|
| 出现概率 | **每局 20% roll 一次，刷 F2 或 F3，同局最多 1 个**（2026-11-27 第三轮；每层独立 roll 作废） |
| 下坠匹配 | **已取消**（无下坠）；改为每局匹配 = **固定 4 层**（2026-11-27 第三轮） |
| 队伍 | **4–6 队（含 AI 队）× 每队 1–4 人、总人数 ≤16、真人 ≥8 才开局**；F1/F4 各 2–3 队、两端人数差 ≤2；允许单/双排整队进同一局，仍不满用 AI（≤4 人 = 2 支 2 人 AI 队）（2026-11-27 第三轮） |
| 同层其他玩家 | 你撤离或下坠不影响他们的对局；你只是离开 |
| 安全层 | **已取消**（2026-11-27）；不再有整备层 |
| 出生/撤离 | **只在 F1/F4 出生**；**对端撤离**：每端 4 个可用点（近层 2 拉闸 / 远层 2 免费），两端不通用；对端免费点不显示、对端拉闸点显示但不可用（2026-11-27 第三轮，06 §4.2） |
| 下坠冷却 | **已取消**（无下坠）；靠出生点与撤离点的图距离约束阻止"开局速撤" |

## 10. 地图与迷雾（2026-11-24 追加确认）

- **撤离点揭示**：以 02 §5.5 为准——进层只给"本层 N 个**本端可用**点"的数量；**远层免费点**到该层自动标出；**近层拉闸点**进拉闸房拉闸后才标出并全楼广播；**对端免费点不显示、对端拉闸点显示但不可用**；拉闸房与楼梯图永久可见（2026-11-27 第三轮）。
- **地图是迷雾形式**：只有已探索区域 + 已揭示的撤离点可见；未探索区域只有楼体轮廓（外墙、核心筒、消防梯）与功能区名称。
- **两级详略**：已探索区域显示真实平面细节（墙体、隔间、门、走廊）；未探索区域只显示功能区名称（如“研发部”“会议室区”），不给任何墙体和连通关系。
- 不显示：战利品、敌人、其他队伍、撤离点占用状态。
- 队友共享探索进度（队伍级），阵亡队员已探索部分保留。
- **开图绝不暂停**：这是在线游戏，没有暂停语义；玩家开图时仍在暴露。地图是半透明覆盖层，可边走边看。
