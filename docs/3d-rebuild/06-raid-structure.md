## 0. 为什么要改

三条已经测出来的事实：

1. **单层 200×160（32,000㎡）÷ 12 人 = 2,667㎡/人**，比塔科夫室内图更稀；体检实测"房间中位 125–219㎡、单门 93–100%、主廊直贯 160–200m"——玩家的实际体验是"12 个人互相找不到"，而不是"太挤"。
2. **"全室内"本身不构成差异化**。塔科夫 Factory / Labs、Dark and Darker 都是室内，证明了可行性；但它们的差异来自"可读模块 + 垂直 + 闭圈压力"，不是"在室内"。差异化应该写在**垂直巨构**上。
3. **"逐层下坠 + 存档层" 与 "每局随机地图" 是两套不同的差异化**，同时做会让玩家既学不会楼、又攒不出进度感；且下坠要求"每层 = 一局独立匹配"，与"一局跨多层"直接冲突。

结论：**保留全室内，把一局做成一栋楼里的"随机垂直切片"。**

## 2. 单局结构：随机垂直切片

### 2.1 为什么不是"4 整层"

每局可玩面积 = 12 人 × 2,100–2,400㎡ ≈ **25,000–29,000㎡**（研究结论）。
4 整层 = 128,000㎡ → 密度掉到 1/10，变成空楼马拉松。所以**必须只开部分楼板**。

### 2.2 切片规则

- **不设楼层总数**（2026-11-27 拍板）：一局匹配直接生成 **3 层（约 55%）或 4 层（约 45%）**，每层开 **20–32%** 楼板，起始楼层号随机；本局之外没有其他层。
- 合计 **24,000–30,000㎡**，硬约束：不在区间内就重抽。
- 开放区不只是"一条横带"：主带 + 三个竖向核（西梯 / 核心筒电梯 / 东梯）+ 连接短廊，三座核**每层都开**，
  所以跨层通路是结构保证（R5/R6 落地为 `SlicePlanner` / `VerticalLinkPlan`）。
- 未开的楼板用**世界内原因**封死：断电、施工围挡、坍塌、封锁带、水淹。它们同时是**免费边界压力**。
- 切片必须是**连通的**：相邻层之间固定 3 条竖向通路（见 D7 / §3.3），坐标逐层完全一致（误差 <0.5m）。
- **同一 buildingSeed 跨局复用同一栋楼**：楼层主题与结构固定，本局只是随机抽 3–4 层（§8.2 #12）；不做长期进度。
- 实现现状：`SlicePlanner.Generate(seed)` 出 3–4 层、每层 `OpenFraction` 0.20–0.32、总量 24,000–30,000㎡；
  `VerticalLinkPlan` 一局只算一次核坐标，逐层下发（`FloorSpec.UseCores`）。

### 2.3 时间轴（30 分钟）

| 时间 | 阶段 | 事件 |
|---|---|---|
| 0–6 | 进楼 / 定向 | 出生在服务节点；看疏散牌与楼层号找脊；低价值外围 |
| 6–14 | 中层推进 | 第一波遭遇；主力搜刮 |
| 14–23 | 核心汇聚 | 高价值点；PvP 集中 |
| ~12 或 ~18 | **电力重组** | 部分门解锁、部分电梯停、某层封锁；撤离点状态变化 |
| 23–28 | 撤离跑动 | 拉闸 / 广播 / 路线被堵 |
| 28–30 | 关闭 | 逐层断电封锁，最后警告 |

## 3. 四条"不随机"的语法层

固定地图靠"记住几何"导航，随机地图只能靠"记住语法"导航。以下四件每局都一样：

### 3.1 竖向价值梯度

- 地下 / 裙房底层 = 低价值入口与管廊（教程区、AI 多、撤离多）
- 中层 = 办公 / 医疗 / 物流，中价值、遭遇密度最高
- 高层 = 数据 / 核心 / Boss，高价值、撤离少、钥匙门禁多

玩家不需要地图就知道"往上还是往下有钱"。（2026-11-27：取消“深度=难度”；**价值梯度保留**，只影响战利品价值场，见 §8.2 #11）

### 3.2 每层"一脊一环"

- **脊**：沿中庭/主廊的贯通动线，宽度 4.8m，每 26–32m 一个断点。
- **环**：绕核心筒一圈的环廊，净宽 2.4–3.0m。
- 迷路时的恢复动作只有两个：**找脊、找环**。这保证随机楼层"永远能回到已知结构"。

### 3.3 竖向核固定对位

- 电梯组 / 剪刀梯 / 货梯井固定在**中央或固定象限**，每层位置一致（跨层对齐）。
- 相邻两层至少 **3 条**通路（2 楼梯 + 1 电梯/货梯/管井），且**不全在同一象限**。
- 这是"多层匹配"的答案：随机的是房间，固定的是竖向核。

### 3.4 每层 1–2 个不可混淆的地标

中庭、涡轮厅、食堂、反应堆、装卸大厅。靠**体量 + 层高 + 光色 + 声音**区分，不靠贴图。地标同时承担两件事：导航锚点 + "能看 ≥60m"的开阔感来源。

## 4. 出生与撤离：按图距离配

### 4.1 出生点

- 只放在**边缘服务节点**：地下装卸口、屋顶停机坪、服务梯、后门、货梯厅。
- 约束（全图，按最短路径的图距离）：
  - 任两处出生点的图距离 ≥ 全图最长最短路的 **35%**
  - 每队出生点到最近撤离点的图距离 ≥ 全图的 **50%**（现有 `FloorValidator.FarThreshold` 的跨层推广）
  - 每队出生点绑定不同竖向核
- 单局**最多 12 人：≤6 队、每队 ≤4 人，最多 3 个满编队**（4+4+4）；允许单/双排，整队匹配进同一局，剩余席位由 1–3 人队补位，仍不满用 AI（§8.2 #8）。

### 4.2 撤离点

- **不按队伍绑定**：每层启用 4–6 个共享撤离点（02 §5），天然成为冲突点；全图 5–7 种设施类型，分散在不同层。
- 至少 1 个要求**垂直机动**（屋顶 / 货梯井 / 地下管廊）。
- 至少 1 个是**拉闸型：会全楼广播**（暴露位置与"我要走了"）。
- 至少 1 个是**静默型**：不广播（例：污水/管廊，读条更长且必须丢包）。
- 撤离读条 10–30 秒，被打断只取消重来，不算失败。
- 最后 3 分钟关闭 1 个非消防出口，但保证每个玩家仍有 1–2 个可用。

## 6. 声音与信息

- **声音是主感官**：脚步材质分区（地毯/硬地/金属格栅/水磨石）、机房轰鸣与负压风机做天然掩噪区、枪声在楼里可跨层听。
- 撤离广播 = 用声音给"等待"定价（反 camp 的核心手段），比几何约束便宜。
- **diegetic wayfinding**：疏散指示牌、楼层号、"你在这里"平面图牌、电梯面板。生成几何时顺带生成这些牌子，玩家学"看牌子"而不是"背地图"。
- **情报道具**：进门前可购买"某层平面 / 一条撤离路线"，局内可捡到安保终端扫出一层轮廓。信息本身是战利品与风险选择。
- **迷雾地图**（沿用 00-decisions §10）：已探索显示细节，未探索只给楼体轮廓与功能区名；开图不暂停。

## 7. AI 玩家与原生 AI

- 原生 AI 25–35 / 切片（旧值 30–40/层），按区域巡逻，枪声与击杀会吸引周边。
- AI 玩家补位：只补满 12 人，遵守与真人相同的搜刮 / 撤离 / 损失规则；会换弹、会退、会绕后，但不做完美预瞄；掉落不低于同档位真人（不做提款机）。
- AI 补位 **≤4 席**；真人 <8 不进局，等待上限 60s 后带 AI 开局（§8.2 #7）。

### 9.2 生成器改造（按依赖顺序）

1. **SlicePlanner**：选层 + 选区（24,000–30,000㎡）+ 封死区 + 连通性校验。
2. **VerticalLinkPlan**：竖向核跨层对齐、相邻层 ≥3 条通路且不同象限。
3. **门数规则**：废掉 `area < 380 → 1 门`，改为按面积/类型出 2–3 门。
4. **走廊断点**：每 26–32m 插入合法断点（交叉口 / 凹位·门斗 / 可穿行房间），不砌墙。
5. **房间尺度重分布**：目标中位 90–130㎡（现状 125–219）。
6. **设施语法库**：替换办公室语法（12 类设施 + 每层 3–4 种主题）。
7. **环路注入**：由核心筒 / 中庭驱动外环 + 内环 + 局部环。
8. ~~**GraphDistance 校验**：出生/撤离按图距离，替换现有直线 `FarThreshold`~~ —— **已完成**（R7 已用图距离，2026-11-27 确认）。
9. **SignageGenerator**：疏散牌 / 楼层号 / 平面图牌 / 电梯面板。
10. **体检器接回归**：见 §10。

## 11. 风险

- **切片封楼板**：如果封得太随意，玩家会觉得"这局地图是残缺的"。需要把封死做得**可读**（围挡/水淹/封锁带 + 广播/牌子解释）。
- **12 人分 3–4 层**：每层实际只有 3–6 人，如果竖向通路太少会变成 3–4 张独立小图。靠"竖向核 + 价值梯度"把动线叠在一起（§3）。
- **程序生成巨构没有先例**：导航与可读性只能靠 diegetic 手段，必须在白盒阶段就测"第一次进楼 30 秒能不能定住方向"。
- **AI 补位**：占比过高会让"遇到的是 AI"变常态，需要上限与行为分档。
