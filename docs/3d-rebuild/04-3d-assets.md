# 3D 资产规范（灰盒 → 真模型）

生成器只产出「名字 + 占地矩形」，真模型通过 `PropCatalog` 映射。这样美术迭代不需要改任何生成器参数，也不需要重烘场景。

## 1. 接入方式

1. 打开 `game/Assets/_Project/Data/PropCatalog.asset`（首次由 M1 构建自动创建）。
2. 每行填一个 `Entry`：`Name`（必须与生成器的 PropSpec.Name 完全一致）、`Prefab`、`Size`（宽/高/深，米）。
3. `Prefab` 有自己碰撞体就把 `AddBoxCollider` 关掉，否则运行时会补一个 `BoxCollider`。
4. 名字没填的行继续用合并灰盒，不会报错。

生成器当前会产出的名字：

| 分类 | Name |
|------|------|
| 大件（1.4–2.2m，挡视线） | 双柜组、纸箱堆、会议桌 |
| 中件（1.2–1.8m，跨蹲） | 办公桌、打印台、沙发 |
| 小件（0.4–0.6m） | 折叠椅、饮水机、小纸箱、垃圾桶 |
| 结构 | 隔断墙（生成器自绘，不走 prefab） |

## 2. 建模规范（必须遵守，否则摆放会错位）

- 1 unit = 1 米，导出前确认缩放是 1，不要用 `Transform.localScale` 假装尺寸。
- pivot 在**底面中心**（脚踩地面那一点），不是几何中心。
- 正面朝 **+Z**；生成器会按走廊方向把长轴转到 ±90°。
- 只有一个胶囊/盒子碰撞体；**不要 MeshCollider**（一层 800 件，MeshCollider 会炸物理）。
- URP Lit 材质，贴图 ≤1K，同类物件共享同一张图集（目标 ≤8 张图集/层）。
- 面数：大件 ≤1500、中件 ≤900、小件 ≤300，且各带一级 LOD（LOD1 约 40% 面数，40m 外切换）。
- 静态批处理：prefab 根节点勾 `Static`（Batching Static）。

## 3. 摆放不合理的排查顺序

1. 位置偏 → 检查 pivot 是否在底面中心。
2. 埋进墙里 → 检查 `Size` 是否大于生成器给的占地（生成器按 `PropSpec.Width/Depth` 摆放，不会为你缩放）。
3. 朝向反了 → 检查正面是否 +Z。
4. 悬空/穿地 → 检查 pivot 高度是否为 0。

## 4. 性能预算

一层约 800 件掩体。真模型上线后必须保持：单层 Draw Call < 3500，1080p 60fps（GTX 1060 级别）。先做 6–8 个样本（大件 2、中件 3、小件 3）验证密度，再批量生产。
