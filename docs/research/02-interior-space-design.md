# 02 · 室内空间设计：房间 / 走廊 / 门 / CQB 理论

> 适用范围：*ESCAPE FROM WORK*（团结 1.11.1 / Unity 2022.3.62，第一人称 PvPvE 搜打撤，办公巨构）。
> 本文是**建筑与关卡设计层**的调研，不评价具体游戏作品。所有数值标来源与可信度：
> **A** = 法规 / 条令 / 标准原文；**B** = 一手设计教材 / 厂商技术手册 / 军事条令图表；**C** = 行业经验与二手总结；
> **D** = 本文推导（需实机试玩校准，不要当定论）。
> 与 [02-level-design.md](../3d-rebuild/02-level-design.md) 的关系：那篇是**生成器的实现口径**，这篇是**这些数字为什么是这些数字**，以及它漏掉的量（门宽、转角、竖向出口距离、房间战斗分类）。两者冲突处见 §6。

**一句话结论**：办公巨构不是“放大的办公室”，而是**每 4,000㎡ 一个街区**的城市尺度室内。战斗空间的最小单位不是房间，而是**“一次 reposition 的距离”（约 7–9m 对角）**；走廊的最小单位不是宽度，而是**“一段 26–30m 的可近战区间”**；可读性的最小单位不是灯，而是**“每个街区一个地标”**。

### 1.5 掩体表

| 高度 | 类别 | 实例 | 弹道 |
|---|---|---|---|
| ≥1.75m | 全掩体（挡视线 + 挡弹） | 服务器机柜 2.0m、档案柜 1.8m、隔断墙、电梯井壁 | 不可穿透 |
| 1.00–1.25m | 半掩体（蹲下挡弹，站姿露头） | 矮柜 1.1m、格子间 53in 板 = 1.35m（偏高）、沙发背 0.9m（勉强） | 部分可穿 |
| 0.70–0.80m | **不算掩体**（只挡蹲姿） | 办公桌 0.75m、会议桌 0.75m、茶水台 0.9m | 桌面木板可穿 |
| ≤0.50m | 障碍物 | 纸箱、椅子、打印机 | 可跨、可穿 |

- 三档划分来自 Naughty Dog《Uncharted 4》的官方掩体规范：高掩体 ≥1.75m、低掩体 1.0–1.25m、≤0.5m 不算掩体 [B: LDB Cover](https://book.leveldesignbook.com/process/combat/cover.md)。
- 掩体宽度 ≥1.20m 才能“完整躲进去”；同侧连续掩体 ≤3 组（约 6–8m）；掩体间距 **4–6m**（一次冲刺 0.8–1.2s 可达）[D]。
- 自由站立掩体（四面可绕）会诱发“绕圈对枪 ring around the rosie”，只放在高潮房间，不放走廊 [B: LDB Cover]。
- 软掩体：布面办公隔断挡视线、不挡弹；玻璃隔断可破、破前双向暴露——这两类是办公室独有资源（见 §3）。

| 距离 | 玩法含义 | 来源 |
|---|---|---|

| 25–40m | 走廊压制区，需要预瞄 | [C: 多数武器有效距离 <40m](https://steamcommunity.com/groups/ANPA/discussions/4/1470841715960578052/) |
| 40–80m | 长走廊狙击，室内应避免 | “30–80m 决定哪边是前方” [C: signposting](https://gamedesignerx.com/blog/signposting-without-waypoints-guiding-players-with-landmarks-light-and-sightlines) |

**硬规则**：任意直走廊视线 ≤30m（本作已定）。30m 处一个冲刺目标只需 6s 就能贴脸，而 30m 外的人形在 1080p 下只有约 30px 高——既看不清也无法公平交战。

### 1.8 生成器校验器新增规则（可直接落成 validate 步骤）

    R1  房间可战斗性：面积 ∈ [56, 90] ㎡ 或 ≥200㎡；40–56㎡ 仅允许作为储藏/卫生间/管井
    R2  房间门数：面积 ≥80㎡ → ≥2 门且通向不同相邻空间；40–80㎡ → 1 门允许但该房间 3m 内需有第二条路
    R3  门位：门中心距最近墙角 ∈ [0.15, 0.5] ∪ [0.9, 1.5] m，禁止 [0.5, 0.9]
    R4  门对门：两门中心连线若同时穿过两个门洞，错位 ≥1.1m 或插入门斗
    R5  门洞净空：门内外各 2.5m 内不得有高价值容器（fatal funnel）
    R6  走廊直段：单段 ≤30m；超过则插入 0.5m 隔断（已实现）
    R7  交叉口：开口 ≥3.0m、净空区 ≥4.8×4.8m、内部无掩体
    R8  掩体：同侧连续 ≤3 组，组间距 4–6m，任何截面通行净宽 ≥2.4m（已实现）
    R9  竖向出口：任意可走点沿路径到最近楼梯/消防梯/电梯 ≤76m（IBC 有喷淋 250ft）
    R10 街区：每 4,000㎡ 块 ≥1 个地标（中庭/大屏/挑空/主题色）+ ≥1 个竖向出口
    R11 房间对角线：战斗房对角 ≥7.0m（8m 柱网即 8×8 = 11.3m 或 7×8）
    R12 死路：死路房间 ≤8%，且死路走廊 0 条
    R13 吊顶可穿面：吊顶板打穿后不得暴露“虚空”，必须能看到结构楼板或设备

## 2. 理论：为什么是这些数字

### 2.1 可读性（readability）与定向（wayfinding）

关卡设计里的 readability 不是“好看”，是**玩家能否在 0.5 秒内从画面里推断出三件事：这是哪、能不能过、哪里危险**。Epic 的官方教程把它拆成简洁性（几何体可被心算）、清晰性（形状一眼可分）、明确动线 [B: Epic](https://dev.epicgames.com/community/learning/tutorials/y587/unreal-engine-fortnite-7ce262)。Level Design Book 进一步区分 wayfinding（定向 + 导航）与 guidance（引导），并反对“骗玩家以为自己在探索”的旧正统，主张给玩家**工具和信息** [B: LDB Wayfinding](https://book.leveldesignbook.com/process/blockout/wayfinding.md)。

对办公巨构，可读性必须**分级实现**，因为单层 32,000㎡ 已经超过人的空间认知上限（真实甲级写字楼标准层通常 1,000–3,000㎡ 连续楼板 [C: SFL 年报](https://www.fonciere-lyonnaise.com/wp-content/uploads/2024/03/ri-deu-2023-va.pdf)）：

| 尺度 | 可读性任务 | 手法 |
|---|---|---|
| 全层（200×160m） | 我在哪个象限 | 四象限主题色 + 主走廊环线 + 唯一核心筒 |
| 街区（4,000㎡，50×80m） | 我在哪个街区 | **每块一个地标**：中庭、挑空、水景、巨型屏幕、破损天窗 |
| 房间（60㎡） | 门在哪、掩体在哪 | 门偏角 + 至少 1 个 full corner + 灯光对比 |

地标要与环境形成**对比**才有层级：高度（矮空间中的高塔）、密度（密排房间中的开阔中庭）、朝向（斜向物体打破 8m 正交网格）、形状（矩形群中的圆形）——这四招抄自《Architecture: Form, Space, and Order》的构图层级 [B: LDB Composition](https://book.leveldesignbook.com/process/blockout/massing/composition.md)。另有研究把 landmark / boundary 这类线索系统化为视觉线索参考指南来提升空间定向 [C: ACM](https://dl.acm.org/doi/full/10.1145/3723498.3723826)，以及以“对称放射布局 + 中心地标”实现任意角度可读的关卡案例 [C: SMU Guildhall](https://scholar.smu.edu/cgi/viewcontent.cgi?article=1048&context=guildhall_leveldesign_etds)。

**注意**：LDB 明确质疑“前景—庇护（prospect-refuge）”理论在关卡设计中的适用性——现实中的安全/信息逻辑与游戏不同 [B: LDB Prospect-Refuge](https://book.leveldesignbook.com/process/blockout/massing/prospect-refuge.md)。别把“高处一定安全”当教条；本作里高处恰恰**最危险**（视野好 = 被三方看见）。

### 2.2 Affordance 与 signifier

affordance 是物体“能做什么”，signifier 是“看起来能做什么”的可感知部分——Norman 2008 年纠正说，设计师真正能控制的只有 signifier [C: Interactions](https://interactions.acm.org/archive/view/november-december-2008/the-way-i-see-itsignifiers-not-affordances1)。对室内射击游戏，这意味着**每一类交互物必须有独占的轮廓 + 材质 + 音效**：

| 物体 | affordance | signifier 要求 |
|---|---|---|
| 门 | 开 / 关 / 锁 / 破 | 把手高度统一 1.05m；锁用红色读卡器；破门用可见合页/划痕 |
| 玻璃隔断 | 看穿 / 打穿 / 撞碎 | 反光 + 边框 + 弹孔裂纹分级（3 级才碎） |
| 吊顶板 | 打穿 / 窥视 / 投掷 | 水渍、翘边、缺失板 = “这里能上去” |
| 家具 | 掩体 / 可翻越 / 可搜 | 高度即台词：≥1.75 站后、1.0–1.25 蹲后、≤0.5 跨过 |
| 管井门 | 只能开、进不去 | 窄、矮、有锁——形状本身就是“这不是路” |

可读性的敌人是**均匀**。办公室天然的均匀（同样的格子间、同样的门、同样的吊顶）是本作最大的设计风险，必须靠“损坏状态、灯光、水渍、翻倒的家具”制造局部差异。

### 2.3 Critical path vs exploration：搜打撤没有 golden path

critical path（黄金路径）是“完成单人关卡的主路径”，LDB 自己也说它主要用于单人脚本化关卡，不适用于多人，且只是**理想设计意图**，玩家会乱走 [B: LDB Critical Path](https://book.leveldesignbook.com/process/layout/criticalpath.md)。本作是 PvPvE 搜打撤，没有强制路径，只有**价值梯度 + 撤离向量**。替代模型：以出生区为圆心、撤离点为方向的**三个同心带**。

| 带 | 距出生 | 战利品密度 | 遭遇概率 | 设计目的 |
|---|---|---|---|---|
| 出生带（0–60m） | 近 | 低 | 低 | 给新手 30s 安全期，学会读图 |
| 中环（60–150m） | 中 | 中 | 中 | 主战场，走廊与交叉口的价值 |
| 核心 / 远端（≥150m、≥60% 对角线） | 远 | 高 | 高 | 与撤离点绑定，制造“带着战利品走回去”的张力 |

这与已定的“高价值房离撤离点 ≥25m”“出生区到撤离点 ≥60% 对角线”一致；本文补充：**价值必须随“回程距离”上升，而不只随“深度”上升**，否则玩家会无脑下坠、不搜刮。

### 2.4 Macro / micro loop 与 pacing

- **micro loop（0.5–15s）**：听 → 探头 → 射击 → 换位。成败由**掩体间距**决定（4–6m 是 1 秒内可达的距离）[D]。
- **macro loop（2–5 分钟）**：进入街区 → 搜刮 2–3 个房间 → 交战 → 撤离 / 下坠。单层 10–15 分钟 = 4–6 个 macro loop，正好对应 8 个 4,000㎡ 街区中的 4–6 个。
- **pacing 五要素**：Scope / Hierarchy / Causality / Information / Intensity [B: LDB Pacing](https://book.leveldesignbook.com/process/preproduction/pacing.md)。Intensity 必须**有起伏**：把“茶水间 / 卫生间 / 安全层”当 rest beat，把“中庭 / 核心筒 / 撤离点”当 accent。
- beat 的音乐式编排：pulse（每层以撤离点收尾）、accent（撤离读条被偷袭）、rest（安全层）、motif（每层都有的核心筒）、variation（不同楼层主题）、syncopation（Boss 层突然改成通高大厅）[B: LDB Pacing]。

**实测指标（D）**：单层 12 人、10–15 分钟，若玩家平均每 45–70s 遇到一次“可听 / 可见的他人线索”（枪声、脚步、开门吱呀），节奏就成立；若 2 分钟没有任何线索，说明街区过大或隔断过多。

### 2.5 Gating：门禁、供电、破窗

gate = 任何阻断 flow 的东西；分 hard gate（必须解开）与 soft gate（可绕行但有代价），还有 hidden exit（隐藏出口）；lock-and-key 的黄金法则是**先展示锁、再给钥匙、拿到钥匙时提醒锁的位置** [B: LDB Gates](https://book.leveldesignbook.com/process/layout/typology/gates.md)。本作可直接映射：

| 类型 | 本作实现 | 作用 |
|---|---|---|
| hard gate | 全楼封锁（门禁全锁，需卡或破拆） | 强制玩家改变路线，制造“绕远”张力 |
| soft gate | 停电（需供电才能用电梯撤离）、漏水（部分房间封闭） | 让同一张图在不同局有不同通行结构 |
| hidden exit | 管井、吊顶、擦窗机吊篮 | 奖励读图能力，给被堵的人第二条命 |
| forward gate | 下坠口 | 推进节奏 |
| backward gate | 撤离点、安全层 | 退出节奏 |

关键：**电梯必须是 soft gate 且是最大 choke point**。真实世界里电梯厅 3.0m 深、14–25㎡，是楼层里唯一的“必经窄口”；搜打撤游戏里电梯 / 楼梯被公认为高风险 choke [C: The Midnight Walkers](https://www.dlcompare.in/gaming-news/the-midnight-walkers-how-to-survive-a-vertical-extraction)。建议电梯开门前给 1.5s 机械音预警，把“守电梯”从信息不对称变成可博弈。

### 2.6 CQB 空间类型学的可转化部分

军事条令里对本作有用的只有四条，其余（队形、火力扇面）不适用于 12 人 PvP：

1. **fatal funnel（死亡漏斗）**：进门第一动作是“离开门洞正前方”，门洞内外各 2.5m 是死亡区 [B: ATP 3-06.11](https://irp.fas.org/doddir/army/attp3-06-11.pdf)。→ 房间门内 2.5m 不放战利品、不放主掩体。
2. **points of domination**：支配点不应在门窗正前方，所有人应贴墙；第四人越过门洞**至少 1m** 后才占据支配位 [B: ATP 3-06.11 / DTIC ADA428443]。→ 房间“有效角落”是贴墙 1m 内的位置；每个房间有 1 个“不可站”位（正对门的那个角）。
3. **near corner / far corner**：进门必须先清近角再清远角；门越靠近墙角，近角越难清。→ **门中心距墙角 0.15–0.5m** 时，近角形成一个约 1.5㎡ 的贴脸盲区（设计上想要的紧张感）；距离 ≥0.9m 时房间可被“切派”逐步清理（slicing the pie）。
4. **清理电梯需 4 人**（2 人清、1 人破门 / 按钮、1 人警戒）[B: ATP 3-06.11]。→ 单人清电梯几乎必死，所以电梯应做成“有预警、可放弃、可埋伏”的软目标。

实弹 shoot house 的尺寸给了另一组参照：4,200 sq ft（390㎡）/ 17 内门 = 平均每个门后约 23㎡；6 房方案约 65㎡/房；最窄走廊 0.89m × 7.8m [B: t1g](https://t1g.com/site-feature/shoot-house/)。**训练房的房间比游戏房小**，因为它训练的是技术动作而不是战斗节奏——这解释了为什么“36㎡ 也能打”，但那不好玩。

### 2.7 走廊与环路

- **单走廊**（dead-end corridor）制造单向压力：防守方只要看住一端。适合做“必经之路”，不适合做主场。
- **环形走廊**（loop）制造双向压力：任何交火都有“绕后”解，也给被压制方撤退解。本作“任意两点 ≥2 条路径”就是在强制环路，方向正确。
- **T / Y 路口**：三向交叉火力，是天然的“必须快速通过”节点；开口 <2.4m 会卡住并排玩家，<3.0m 会卡住 AI 寻路 [D]。
- **长直走廊屠杀**的数学：30m 走廊、5.0m/s 冲刺 = 6s 暴露；一个持枪防守方在 30m 上命中静止目标几乎必然。对策三条：① 直段 ≤30m；② 每 26–32m 用 0.5m 隔断从一侧内切（已实现，等于给走廊加“半个转角”）；③ 隔断左右交替，形成 2.4m 侧身通道。三条合起来把“一条走廊”变成“三段短兵相接”。
- 光有隔断不够：**走廊必须有侧向出口**。每 20–30m 一个门 / 凹位，让被压制方有“进房间”的选项，否则隔断只是把屠杀点挪了个位置 [D]。

### 2.8 垂直性

垂直变化体现进程、帮助定向（往上 = 目标，往下 = 深入），但竞技射击要慎用：CS 玩家把鼠标灵敏度调得很低，频繁高低差会破坏瞄准，所以 CS 地图普遍平坦；解法是**把微小高差合并成 floor plane**，不要叠 10 层互相重叠的平面 [B: LDB Verticality](https://book.leveldesignbook.com/process/layout/flow/verticality.md)。本作的对策：

- 每层内部保持**一个主 floor plane**（3.37m 净高），高差只出现在夹层（+3.37m）、挑空（8–12m）、楼梯平台。
- 垂直优势给“信息”而不是“无敌”：高台能看到大厅，但栏杆只有 1.1m，上半身暴露。
- 电梯 / 楼梯 / 管井是**唯一可靠的竖向通道**，天然 choke point，也是“守层”与“下坠”的博弈点。环形坡道式设计（每个点都有两个方向、无唯一制高点）是反制“守楼梯”的另一种思路 [C: GameRes](https://www.gameres.com/858141.html)。

### 2.9 空间尺度与移动速度：把“贴脸”算出来

**最小战斗距离**（D，依赖 §1.1 的 5.0m/s 与 0.4s 反应）：

    D_react = v × (t_react + t_aim) ≈ 5.0 × (0.35 + 0.25) = 3.0 m
    D_fight = D_react + d_cover(4~6m) ≈ 7~9 m   ← 房间对角线的最小值

| 房间对角 | 面积（正方） | 结论 |
|---|---|---|
| <5m | <25㎡ | 纯伏击房 / 储藏，不要放 AI |
| 5–7m | 25–56㎡ | 贴脸遭遇，先手必胜；只适合“转角惊喜” |
| **7–10m** | **56–113㎡** | **最小可玩战斗房**：一次 reposition + 一个掩体轮换 |
| 10–16m | 113–290㎡ | 标准小队战房 / 小会议厅 / 开放办公的一个组团 |
| >20m | >400㎡ | 大厅：需要 ≥3 条进出路径，否则变成靶场 |

→ **直接结论**：本作“最小房间 40㎡”对战斗房偏小。建议 40㎡ 只保留给储藏、卫生间、管井；战斗房下限提到 **56㎡（7×8m）**，标准值 **64㎡（8×8m，正好一个柱网）**，大厅 ≥200㎡。

## 3. 办公空间作为战斗场景的特殊性

办公楼的每个房间都自带“真实功能”，在关卡设计上等于**免费的类型学**——功能决定家具，家具决定掩体，掩体决定战斗。下表把真实做法、战斗意义、搜刮意义对齐。

| 空间 | 真实做法（尺寸 / 规范） | 战斗意义 | 搜刮意义 |
|---|---|---|---|
| **格子间 / 开放办公** | 工位 6×6 ft = 1.8×1.8m（3.3㎡）；隔板高 47/53/67 in = **1.19 / 1.35 / 1.70m** [B](https://officestation.com/guides/cubicle-size-guide/)；通道 1.2–1.5m | 半掩体迷宫：53in 板 1.35m 挡站姿露头、67in 板 1.70m 接近全掩体；布面隔板**挡视线不挡弹** → 最强听声空间 | 抽屉 / 桌面 / 主机 / 私人物品，单件价值低、密度高；“以量取胜”的搜刮带 |
| **会议室** | 6 人 12–15㎡；座席 1.8–2.4㎡/人，视频会议 2.4–3.0㎡/人 [B](https://www.coohom.com/article/standard-meeting-room-size-essential-guide-for-modern-workspaces) | 玻璃隔断 = 双向暴露 + 可破；长桌 0.75m 只挡蹲姿；门少 → 天然 choke；投影幕是唯一 full cover | 投影仪、白板、笔记本、签字文件；中价值、易识别 |
| **茶水间** | 8–15㎡；台面深 0.6m、高 0.9m；冰箱 0.7×0.7×1.8m | 台面 + 冰箱 = 半掩体 + 全掩体组合；咖啡机是天然声音诱饵（暴露位置） | 消耗品：食物、水、医疗、咖啡因类 buff；“休息 beat”的物理载体 |
| **机房 / 数据中心** | 机柜 0.6×1.2×2.0m；冷通道 1.2m（ANSI/TIA-942-A 推荐）、热通道 0.9–1.2m [B](https://www.conteg.com/solutions/hot-cold-aisle) | 全掩体阵列 + 1.2m 窄通道 = 中距离（8–20m）最强战斗空间；噪音掩盖枪声 | 硬盘、GPU、备份磁带：**最高价值密度**，也是最高风险房 |
| **档案室** | 密集架楼面荷载 1,200–1,500 kg/㎡（固定架 600）[B](https://fr.m.wikipedia.org/wiki/Rayonnage_mobile)；移动架需留开启通道 | 高柜阵列 = 全掩体 + 极窄过道，转角遭遇战；移动架可做成“能推开的动态掩体” | 文件、印章、证物：高价值、低重量、不占背包 |
| **楼梯间** | 净宽 1.12m（法规）/ 建议 1.4–1.8m；踏步 178×279mm；剪刀梯 = 两部梯交叉 | 单向线性空间，有上下视野、无侧向出口，**全楼层最大 choke**；平台是唯一对射位 | 低；消防箱、工具、偶尔的遗落物 |
| **电梯厅** | 3.0m 深、14–25㎡；消防电梯厅 ≥14㎡ 且最小边 2.44m [A](https://www.iccsafe.org/wp-content/uploads/ctc/ElevatorLobby-with-notes.pdf) | 开阔 + 无掩体 + 唯一出口 = 埋伏圣地；电梯轿厢是“移动的 fatal funnel” | 低；门禁卡、楼层指示牌（信息类） |
| **管井 / 强弱电井** | 1.2×1.2 ～ 2.0×3.0m，竖向贯通；检修门 0.6–0.9m | 单人垂直捷径；可作“只闻其声”的通道；不可作为主路径 | 线缆、工具、维修记录 |
| **吊顶 / 设备层** | 净高 3.37m；设备层 0.8m（ASHRAE 建议静压箱 ≥0.45m）[B](https://airwiseparts.com/blog/ceiling-plenum-space-guide/)；矿棉板 600×600 | 0.8m 不能爬行 → 只能打穿、窥视、投掷；手雷在吊顶上弹跳；打穿后露出风管与桥架 | 藏匿物（吊顶夹层是天然的“藏东西”叙事） |
| **打印 / 复印区** | 3–6㎡ 开放凹位，通常在主走廊边 | 半掩体 + 噪音；走廊上唯一的“凹位”，给被压制方一个躲点 | 纸张、墨盒（低价值，但可作“这里有人来过”的线索） |
| **前台 / 接待 / 大堂** | 净高 12m（本作裙房 6.0m / 大堂 12m）；前台 0.75–1.1m 高 | 高台视野 + 开阔 + 极少掩体 = 狙击位也是靶位；视线穿透整层 | 门禁卡、钥匙、登记册（进度类高价值） |

**独有的三条“办公室规则”（D）**：

1. **布面隔断是“半透明明暗”**：挡视线不挡弹——“你看不见他，但流弹能穿过”。这是办公室独有的紧张感，走廊与格子间应大量使用。
2. **吊顶是第三维而非装饰**：0.8m 设备层不能走人，但可以打穿、投掷、让手雷弹跳；这比“能爬管道”更真实，也更适合程序生成（不需要额外寻路层）。
3. **家具高度就是难度曲线**：办公桌 0.75m（不算掩体）→ 矮柜 1.1m（半掩体）→ 档案柜 1.8m（全掩体）→ 机柜 2.0m（全掩体 + 阻挡）。生成器按房间类型抽家具，就自动产出了不同难度的战斗房。

## 4. 建筑学参考：为什么办公巨构长这样

### 4.1 核心筒 + 出租单元 + 走廊

真实甲级写字楼的平面组织是：**核心筒（电梯、楼梯、卫生间、管井、机房）+ 进深 12–15m 的出租单元 + 环核心筒走廊**。核心筒通常占 15–25% 建筑面积，整栋楼 NLA/GFA 效率约 75% [C: CBD 指引](https://www.cbd.gov.au/sites/default/files/2020-09/guidance_note_-_mixed_use.pdf)；设备用房单独占办公 GFA 的 6–11% [C: RLB](https://www.rlb.com/oceania/wp-content/uploads/sites/1/2022/03/NZ_RLB-Riders-Digest-2022_2.pdf)；吊顶后净高 2.45–2.55m（标称 2.7m 层高）[C](https://completeofficefitouts.com.au/blogs/office-ceiling-heights-commercial-fitouts-clearance/)。

对照本作：核心筒 16×12m = 192㎡，只占 32,000㎡ 的 0.6%——**这是巨构，不是写字楼**。所以必须补“多个次级核心”：东西剪刀梯 + 北疏散梯 + 每 4,000㎡ 街区至少一个竖向出口。用 IBC 的出口行进距离反推：有喷淋时 250 ft = 76m [A: WAC](https://app.leg.wa.gov/WAC/default.aspx?cite=51-54A-1017&pdf=true)；8 个街区每块 50×80m，从块中心到边界最长约 47m，加水平绕行后约 60–75m——**恰好一块一个出口**。这条规则比“任意两点两条路径”更能保证“有人追你时你跑得掉”。

采光也是硬约束：自然采光进深约为窗头高度的 2 倍（约 5–7m）[B: Pattern Guide](http://patternguide.advancedbuildings.net/patterns/pattern-15-daylight-from-top-and-side-office-building)，另有“进深不超过开间 2 倍”的经验 [B](https://www.irbnet.de/daten/iconda/CIB_DC22886.pdf)。32,000㎡ 的绝大多数区域**没有自然光**——这既是写实（深进深办公楼的真实状态），也是设计机会：中庭、天窗、灯池必须承担“光的地标”职责。

### 4.2 柯布西耶、通用空间、服务空间

- **柯布西耶五点**（piloti、自由平面、自由立面、横向长窗、屋顶花园）[C: MoMA](https://www.moma.org/artists/3426-le-corbusier-charles-edouard-jeanneret)。其中“自由平面 + 横向长窗”是**双刃**：自由平面让房间可以任意切（生成器合法性的建筑学依据），横向长窗制造**贯穿整层的长视线**——正是 CQB 最怕的东西。所以沿外墙的长窗必须被竖向隔断 / 家具 / 绿植打断，每 6–8m 一个断点。
- **通用空间（universal space）**：密斯的无柱大空间，可自由划分功能——正是“4,000㎡ 街区 + 可插拔隔断”的原型。结构（8m 柱网、楼板）是永久的，房间隔断是临时的。这解释了为什么程序生成在叙事上成立：**公司随时在改办公室**。
- **服务空间 / 被服务空间（served / servant）**：路易·康把设备管井、楼梯、卫生间归为 servant，办公归为 served。战斗上 servant = 硬掩体 + 垂直通道 + 高信息价值（能听到整层），served = 开阔、低掩体、高搜刮价值。这个二分可以直接变成生成器的“房间角色”参数。

### 4.3 开放办公 vs 格子间

格子间不是“设计失败”，是**演化失败**：1960 年代 Robert Propst 为 Herman Miller 设计 Action Office，本意是让办公更灵活自由，结果被企业简化成标准化 cubicle farm，Propst 本人晚年公开表示后悔 [C: CBC](https://www.cbc.ca/radio/thecurrent/the-current-for-march-31-2015-1.3016006/the-design-behind-the-office-cubicle-1.3016038)、[C: CNN](https://www.cnn.com/2012/06/15/living/corporate-creativity-office-workers/index.html)。

这个叙事对本作极其有用：**格子间 = 被资本压平的个性化空间**，正好是“办公恐怖”的视觉语言，也让“千篇一律的迷宫”在叙事上成立。密度上，BCO 现在建议 10㎡/人（原 8㎡/人降为例外）[C: BCO](https://www.bco.org.uk/bco-announces-new-recommendations-for-greener-and-healthier-offices)，所以一层 32,000㎡ 对应约 **3,000 个工位**。12 名玩家对 3,000 个工位 = 密度极低，这决定了战利品不能均匀撒，必须**热点化**：每 4,000㎡ 街区 3–5 个高价值房，其余是低价值“背景搜刮”。

### 4.4 巨构（megastructure）的建筑语言

“megastructure”一词约 1964 年出现，Reyner Banham 的定义关键不在“大”，而在**可用模块化单元建造、能大规模扩展的结构**（永久基础设施 + 可替换单元）[C: HAL 论文](https://hal.science/hal-01816862/file/AGE-2009-ROU.pdf)。Archigram 的 Plug-in City 就是“永久骨架 + 可插拔居住舱” [C: Zenodo](https://zenodo.org/records/21481186)。对本作的直接映射：

| 巨构语汇 | 本作对应 |
|---|---|
| 永久基础设施 | 楼板、8m 柱网、核心筒、竖向井道 |
| 可插拔单元 | 房间隔断、家具、门、吊顶板 |
| 巨型尺度感 | 32,000㎡ 单层、200m 长走廊、8–12m 中庭 |
| 模块化重复 | 8 个 4,000㎡ 街区、同一套房间模板 |
| 未完成 / 施工中 | “施工”事件层、开放楼板、脚手架 |

这也解决了一个叙事难题：**为什么同一层每局都不一样**——因为巨构本来就是“持续施工、持续改装”的机器。

## 5. 建议：办公巨构每层应该有什么房间、各占多少

### 5.1 普通办公层（32,000㎡）配比

| 空间类型 | 面积占比 | 换算面积 | 数量 | 战斗角色 | 战利品权重 |
|---|---|---|---|---|---|
| 开放办公 / 格子间 | **42–50%** | 13,400–16,000㎡ | 6–10 个大区 | 主战场、听声迷宫 | 中（密度高） |
| 会议室 / 洽谈室 | 8–12% | 2,600–3,800㎡ | 40–70 间 | 玻璃房遭遇、choke | 中 |
| 独立办公 / 高管套间 | 6–10% | 1,900–3,200㎡ | 20–40 间 | 套间战、门斗 | 高 |
| 茶水间 / 休息 / 打印 | 4–6% | 1,300–1,900㎡ | 25–40 处 | rest beat、声音诱饵 | 中低（消耗品） |
| 机房 / 弱电间 | 3–5% | 960–1,600㎡ | 8–15 间 | 全掩体阵列、中距离 | 极高 |
| 档案 / 储藏 | 3–5% | 960–1,600㎡ | 15–25 间 | 死路、转角 | 高 |
| 走廊 + 核心筒 + 卫生间 + 管井 | **15–18%** | 4,800–5,800㎡ | — | 连接、choke | 低 |
| 空置 / 施工 / 事件区 | 3–5% | 960–1,600㎡ | 1–3 区 | 变数、临时掩体 | 中 |
| 中庭 / 挑空 / 大厅（若该层有） | 2–5% | 640–1,600㎡ | 1 | 地标、垂直战 | 无（纯空间） |

合计房间数约 **300–500 间**，平均 60–90㎡——正好落在“标准战斗房”区间。门数约 **350–600**。

> 口径：占比按“建筑功能面积”粗计，各区间取中值相加约 101%（46+10+8+5+4+4+16.5+4+3.5），基本自洽；生成时应**先放交通核 / 走廊 / 竖向出口，再用剩余面积反算房间数**，不要逐项精确加和。

### 5.2 分层差异化（10 种原型 → 配比偏移）

| 楼层原型 | 主空间占比 | 关键改动 |
|---|---|---|
| 开放办公层 | 开放办公 55% | 战斗房密度最高，走廊最长 |
| 会议中心层 | 会议 40% | 玻璃房密集，单房面积大，choke 多 |
| 高管层 | 独立办公 35% | 套间 + 门斗多，长直走廊少，价值最高 |
| 数据层 | 机房 35% | 全掩体阵列 + 冷通道，走廊窄（1.8–2.4m） |
| 实验室层 | 实验室 30% | 净高 5.4m，台面 0.9m 半掩体，危险品 |
| 医疗层 | 病房 / 诊室 35% | 小房间多、门多，适合伏击 |
| 物流层 | 仓储 45% | 大空间 + 货架，货运电梯 choke |
| 观景层 | 大厅 30% | 挑空 8–12m，天桥，狙击位 |
| 设备层 | 设备 60% | 1.8m 服务走廊，最容易“被堵” |
| 空置层 | 施工 50% | 开放楼板、脚手架、临时通道 |

### 5.3 每层的四个“必须”

1. **必须 ≥1 个地标**（中庭 / 大屏 / 挑空 / 主题色），在四个象限都能看到。
2. **必须 ≥1 条环线**把该层连成“可以绕后”的图。
3. **必须每个 4,000㎡ 街区 ≥1 个竖向出口**（楼梯 / 消防梯 / 电梯），路径距离 ≤76m。
4. **必须每个街区 1 个 rest beat**（茶水间 / 卫生间 / 休息区），且它不在主走廊直线上。
